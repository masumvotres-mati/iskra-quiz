# Praca nad grami

Przed tworzeniem nowej gry albo zmianą grafiki, animacji lub interakcji przeczytaj [GAME-STYLE.md](GAME-STYLE.md).
To żywe źródło prawdy dla stylu gier w tym repozytorium, wraz z zapisanymi obrazami odniesienia.

Oddzielaj wspólne zasady od parametrów konkretnej gry.
Po zaakceptowaniu nowego wzorca aktualizuj przewodnik, zastępując lub usuwając nieaktualne reguły.
Nie traktuj przypadkowych odstępstw w starszym kodzie jako nowych wzorców i nie nadpisuj automatycznie obrazów odniesienia.
